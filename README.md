## 📱 Описание приложения

Приложение позволяет:
- вводить текст заметки
- сохранять заметки
- отображать их в виде списка
- редактировать существующие заметки
- удалять заметки


## 🛠 Используемые технологии

- Flutter
- Dart
- Material UI
- TextEditingController
- ListView.builder
